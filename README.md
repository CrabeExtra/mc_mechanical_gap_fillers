
Intro
=======

This is a mod from the NeoForged template with the intention of interoperability with ATM10.

I started playing ATM10 on a private server and noticed after some time working through the AE2 mod tree and using 
Mekanism automations to generate resources that there were gaps in my from-scratch resource generation.

Iron is generated by washing gravel using a Create fan and water and then pressing the nuggets into ingots, 
but this is a slow or very vast automation system that takes a while to build. 
I ended up using bees, and then found that the simulation chamber was a much faster alternative. BUT the simulation 
chamber is also a hassle to get sorted, you have to go around *finding* and killing a bunch of mobs, it doesn't work 
with all resource types and there is no way to *quickly* get a high percentage of success rates even late game. Whereas 
using mekansim, with late game resources combined with lots of AE2 patterns you can simply request the system build you
higher quality (and/or more) factories and hook them up to the system. More on simulation chambers is they don't play 
nicely with AE2 patterns. I had to treat them like storage and use filtered import and export buses, which meant I could
only essentially 'start generating iron' or 'stop generating iron'. No 'generate 10 iron'.
